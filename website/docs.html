Aether CLI by Sayanox

Installation

git clone https://github.com/sayan9168/aether-cli.git
cd aether-cli
python -m venv .venv
source .venv/bin/activate   # Linux / macOS / Termux
# .venv\Scripts\activate    # Windows
pip install -e .
cp .env.example .env

Edit .env and add at least one API key (OPENAI_API_KEY, ANTHROPIC_API_KEY, XAI_API_KEY...).

Usage

aether
# or
python -m aether

Commands

CommandDescription
/helpShow help
/clearClear conversation
/model <name>Switch model
/toolsList tools
/infoSystem info
/save <name>Save session
/load <name>Load session
/sessionsList sessions
/exitQuit

Termux (Android)

pkg install python git
pip install -e .
aether

Windows

Works with PowerShell and CMD. If aether is not found, use python -m aether.
